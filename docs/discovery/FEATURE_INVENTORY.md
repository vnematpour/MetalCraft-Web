# فهرست قابلیت‌های مشاهده‌شده

این فهرست از کلاس‌ها و فرم‌های موجود در سورس استخراج شده است. وجود کد به معنی تست‌شدن کامل قابلیت یا تأیید نهایی رفتار کسب‌وکار نیست.

| حوزه | قابلیت مشاهده‌شده | شواهد در سورس | وضعیت |

| کاربران | فهرست، ایجاد، ویرایش، حذف کاربر | `UsersPage`, `UserDialog` | پیاده‌سازی شده |
| کاربران | جلوگیری از حذف کاربر جاری | `UserRepository.TryDelete` | پیاده‌سازی شده |
| مشتریان | فهرست و جست‌وجوی مشتری | `CustomersPage`, `CustomerRepository.GetAll` | پیاده‌سازی شده |
| مشتریان | ایجاد و ویرایش اطلاعات مشتری | `CustomerDialog`, `CustomerRepository` | پیاده‌سازی شده |
| مشتریان | جلوگیری از حذف مشتری دارای سفارش | `CustomerRepository.TryDelete` | پیاده‌سازی شده |

## مواردی که در سورس اثبات نشدند
- نقش‌ها و سطح دسترسی تفصیلی
- ثبت تاریخچه تغییرات هر رکورد (Audit Trail)
- گردش تأیید سفارش یا تأیید مالی چندمرحله‌ای
- انبار و موجودی مواد اولیه
- مدیریت خرید/تأمین‌کننده
- مدیریت دستگاه‌ها و ظرفیت تولید
- اعلان پیامکی/ایمیلی/پیام‌رسان
- API یا اتصال به سامانه بیرونی
- چندشرکتی یا چند شعبه‌ای بودن
- رزرو/برنامه‌ریزی زمان تولید
- مدیریت فایل و پیوست سفارش
